You know the Mending cantrip.

As a Magic action while holding Tinker's Tools, you can create one item in an unoccupied space within 5 ft. of yourself, from the provided list. The item lasts until you finish a Long Rest, at which point it vanishes. You can use this feature 3 times per Long Rest.

   | 3 / Long Rest • 1 Action

* Replicate Magic Item • EFotA 8
You have learned arcane plans that you use to make magic items.

You know 4 Magic Item Plans.

When you finish a Long Rest, you can create 2 magic items. A magic item created by this feature functions as the normal magic item, except its magic isn't permanent; when you die the magic item vanishes after 1d4 days. If you replace a plan you know with a new plan, any magic item created with the replaced plan immediately vanishes. If an item that you created is a container, and it vanishes, its contents harmlessly appear in and around its space.

Additionally, you can use any Wand or Weapon created by this feature as a Spellcasting Focus.
