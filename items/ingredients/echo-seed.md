# Echo Seed

- **Appearance:** Pale seed that clicks softly when rolled.
- **Simple Test:** Roll it around the empty cauldron: it repeats the last tap.
- **Handling:** Test it in the empty cauldron only. It picks up ambient tapping and knocking, so a noisy table can give a false result.
- **Found:** Alchemist Chamber
