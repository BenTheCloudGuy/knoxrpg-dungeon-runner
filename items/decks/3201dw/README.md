# HP 3201dw Deck Variants

These PDFs are HP 3201dw duplex variants. Each copy keeps the original fronts unchanged and rotates the back or rear pages 180 degrees for that printer's duplex behavior.

The original PDFs under `items/decks/` and `items/magic-items/deck/` are the HP 3301dw versions and are unchanged.

Regenerate with:

```powershell
node items\decks\tools\rotate-backs-3201dw.mjs
```
