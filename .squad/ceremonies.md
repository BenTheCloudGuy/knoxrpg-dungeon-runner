# Ceremonies

> Team meetings that happen before or after work. Each squad configures their own.

## Design Review

| Field | Value |
|-------|-------|
| **Trigger** | auto |
| **When** | before |
| **Condition** | multi-agent task involving 2+ agents touching the same room or shared system (e.g., crystal chain, Xhal'theris voice, prize economy) |
| **Facilitator** | Laios |
| **Participants** | all-relevant |
| **Time budget** | focused |
| **Enabled** | ✅ yes |

**Agenda:**
1. Review the task and what's being added or changed
2. Confirm canon alignment with README and prizes.md
3. Identify risks: balance, lethality budget, prize integrity, table logistics
4. Assign action items per agent

---

## Retrospective

| Field | Value |
|-------|-------|
| **Trigger** | auto |
| **When** | after |
| **Condition** | playtest feedback, room rewrite, or canon contradiction surfaced |
| **Facilitator** | Laios |
| **Participants** | all-involved |
| **Time budget** | focused |
| **Enabled** | ✅ yes |

**Agenda:**
1. What happened? (facts only — what playtesters did, what broke)
2. Root cause: design, prose, mechanics, or props
3. What should change?
4. Action items for next iteration
