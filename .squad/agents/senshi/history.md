### 2026-09-06 - Crop marks now track the registration nudge
- Bug: cropSvg drew cut ticks at the fixed grid while buildSheet nudged the CARDS by (BACK_DX, BACK_DY). On the backs page (dy=-2.5mm) the printed cut lines missed that page's cards by 2.5mm; fronts were fine because dx=dy=0.

## Learnings

- 2026-09-16 (Berhan journal renderer full rebuild, user REJECTED prior build): The user rejected the first journal PDF outright and asked for a real rebuild, not a patch, citing 5 defects: a clinical "BERHAN VOSS / BENCH JOURNAL N/16" header, clipped/truncated margin and correction annotations, an HTML-looking flat CSS/SVG page instead of a handwritten one, dead whitespace (worst on page 1), and sketches isolated in a bottom-right corner instead of near the content they illustrate.
- Root cause of the old clipping: the previous SVG + sharp/librsvg pipeline could not reliably embed the intended handwriting font and used char-count-based line wrapping against a fixed box width, so real glyph widths didn't match the wrap math and text ran past the page edge and got cut mid-word.
- Fix: rewrote `props/journal-deck/tools/journal-render.mjs` from scratch on `@napi-rs/canvas` (added as a dependency in a new local `props/journal-deck/tools/package.json`) instead of SVG/sharp/resvg, specifically because `ctx.measureText()` gives real per-glyph widths for accurate wrapping, and because canvas font embedding via `GlobalFonts.registerFromPath()` actually renders the intended font instead of silently falling back to a generic one. Removed the now-unused `@resvg/resvg-js` dependency once the rewrite was validated.
- Downloaded the OFL-licensed Caveat variable handwriting font into `props/journal-deck/assets/fonts/Caveat-Variable.ttf` (with its OFL license file alongside) as the body/heading typeface; this is a real handwriting font, not a decorative web script font, and reads as handwritten rather than typed once rendered through canvas.
- No header of any kind is rendered; each page just opens with its own in-world content (title line, or straight into text for untitled entries). A small unobtrusive page number sits in the bottom corner only, nothing resembling a document slug line.
- Built a procedural parchment texture directly in canvas (paintParchment()): warm tan/cream base with soft noise, a couple of faint circular stain blotches, subtle edge darkening/vignette, and printed ruled notebook lines plus a left-margin rule and three binder-hole dots, all drawn in-code (no external texture asset needed, so there was nothing extra to license). Removed the old rounded-rectangle page border and drop-shadowed margin boxes entirely; margin notes now render as smaller, slightly rotated handwriting stacked in a real right-margin column running down the page rather than floating bordered callouts.
- Sketches now composite (multiply blend, so they read as ink on the page rather than a pasted photo) near the content they illustrate: inline beside the ingredient list/method on recipe pages, near the referenced passage on narrative pages, sized meaningfully larger than the old fixed 300x300 corner square (up to 460x460 on sparse pages) instead of being a small isolated square.
