# Squad Skills

Skills are reusable, opinionated patterns the squad applies to recurring kinds of work. Each one is owned by exactly one agent. When that agent is spawned for matching work, they load the skill and follow it.

If you are an agent reading this: **find your skill below, open the `SKILL.md`, and follow it.** Do not freelance a pattern when a skill already exists.

## Rules

- Skills are opinionated. If you disagree with a skill, propose an update to the user rather than ignoring it.
- The voice rules (no em-dashes, "would a DM say this out loud" test, no flowery prose) apply to every skill. They are not Marcille-only.
- When canon is missing or contradictory, stop and ask the user. Never invent.
- If you find yourself doing the same kind of work three times without a skill for it, propose a new skill.
