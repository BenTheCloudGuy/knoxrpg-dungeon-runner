# Crystals

There are eight Crystal Shards scattered throughout the dungeon, one for each school of magic. The survivors must find all eight Key crystals and place them to force the exit Portal open. There is no required order. Any order works once all eight are present.

The Eight exit Crystal Shards are Green, White, Yellow, Blue, Purple, Red, Magenta, and Black.

Current notes also list extra physical crystals. Treat those as lesser boon crystals unless that changes. Lesser boon crystals are not part of the final exit lock. They do not award prizes and do not create a crystal-to-prize mapping.

## Table Rules

- A crystal's power only works after the crystal is placed on the Scrying board.
- Each power can be used 1 time per game hour.
- Track each crystal's counter in the Scrying Stone admin app or on a visible table tracker.
- Crystal powers stack if one character carries more than one crystal.
- Dead PCs leave Crystal Shards, lesser crystals, gear, coins, and prize Item Cards on their bodies. Survivors can loot them if they can reach the body.
- Crystal Shards are for escape routing, color-locked doors, and forcing the exit Portal open. They are never prize gates.

## Kyber Crystal Programming Notes

These are backstage prop notes for owned Kyber Crystal toy props only. Do not use this workflow for access badges, payment cards, transit credentials, hotel keys, locks, or any system you do not own.

The physical crystals use EM4305 chips running EM4100 emulation. The prop's color is decided by the 32-bit EM4100 tag ID, usually in the `0x00000Cxx` range.

On the EM4305, that ID is stored across words 5 and 6:

- Word 5: `000001FF`, constant for every `0x00000Cxx` ID.
- Word 6: Per-ID value, using the EM4100 stream in bit-reversed form.

Each crystal has its own login password. Recover the password for the specific crystal first, then use that value as `<PW>`.

Current Proxmark3 setup:

- Proxmark3 on `COM6`.
- PM3 Easy coupling is marginal. Seat the crystal flat and centered.
- A coin or spoon on the antenna can re-tune it. Watch `lf tune` voltage.
- Writes may need retries.

### Programming Procedure

Recover this crystal's password first:

```text
lf em 4x05 chk
```

Then program words 5 and 6:

```text
lf em 4x05 write -a 5 -d 000001FF -p <PW>
lf em 4x05 write -a 6 -d <WORD6> -p <PW>
```

Repeat the word 6 write until Proxmark3 reports that it was written and verified.

Confirm the broadcast value:

```text
lf em 410x reader
```

Expected confirmation format:

```text
EM 410x ID 0000000Cxx
```

If a crystal stops broadcasting, restore the EM4305 config:

```text
lf em 4x05 write -a 4 -d 0001805F -p <PW>
```
